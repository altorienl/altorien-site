02

Fly with Friends

84 commits / live
Flights that land a group together, and what that costs

Three or more people leave from different cities and want to arrive at one airport at the same time. The app solves for the tightest arrival window the group can actually make, then prices what that closeness costs against simply booking the cheapest flights and meeting whenever.

  • 578 checks across 12 suites, every one verified able to fail
  • 3,643 airports, metro groupings resolved from the origin side
  • Found and fixed a $387 overcharge the old objective could not see
// What a plan costs the group, in one currency. Replaced two rules
// that had no units between them -- a veto that priced a connection
// at infinity while the same file priced it at $120, and a loop that
// took the first discount and refused every later one. On a live
// search that pair recommended $1,086 with $699 sitting in its own
// ladder, thrown away.
function tripScore(r) {
    return r.total                              // real money
        + SPREAD_PER_MIN * r.worst              // $1.50/min apart
        + EASE_PER_STOP  * r.regret.stops       // a connection
        + EASE_PER_MIN   * r.regret.mins        // time in the air
        + r.late;                               // landing at 1am
}
